Laser Core 0.2.0-beta.2

Laser Core is experimental testnet software. It is not intended to hold assets
of value, and its network and storage formats may reset or change.

No project-wide license grant has been finalized for Laser's first-party
source. The package metadata therefore uses UNLICENSED. Distribution of a
release artifact must not be described as MIT-licensed unless the repository
owner first adopts and commits an applicable project license.

  renderer/assets/Geist-OFL.txt and renderer/assets/GeistMono-OFL.txt.
- Michroma: SIL Open Font License 1.1. See renderer/assets/Michroma-OFL.txt.
- Electron: MIT license. Electron's license and Chromium's third-party license
  notices are embedded in the packaged runtime as LICENSE.electron.txt and
