# Security policy

Laser Core is experimental Shadownet software and must not hold assets of
value.

Please report suspected remote-code-execution, wallet-secret, consensus, or
network-isolation vulnerabilities privately through GitHub Security Advisories
for this repository using [Report a vulnerability](https://github.com/Laser-Chain/laser-core/security/advisories/new).
Do not disclose exploit details in public issues. Include the affected version, platform, reproduction
steps, and logs with wallet keys, passphrases, and RPC tokens removed.

The latest published beta is the target for fixes. Older prereleases may need
an upgrade; there is no promise of backported security updates and no production
mainnet security-support window during beta. Development commits and locally
prepared packages do not update an installed release.
